# Medicare Hospital Management System

A desktop hospital management application built with C# and .NET Windows Forms.

## 🏥 Overview

Medicare Hospital Management System is designed to streamline administrative and clinical workflows in healthcare facilities. It provides modules for managing patients, doctor appointments, billing, staff, and medical records.

## 🛠️ Built With

- **Language:** C#
- **Framework:** .NET 10.0 Windows Forms (`net10.0-windows`)
- **IDE:** Visual Studio 2026 / Visual Studio Code

## 🚀 Getting Started

### Prerequisites

- [.NET 10.0 SDK](https://dotnet.microsoft.com/download)
- Visual Studio 2026 or later (with *.NET desktop development* workload)

### Running the Application

1. Clone the repository:
   ```bash
   git clone https://github.com/ATHEEF07/MEDICARE-HOSPITAL-MANGEMENT-SYSTEM-.git
   ```

2. Open the solution:
   Open `MEDICARE HOSPITAL MANGAMENT.slnx` in Visual Studio.

3. Build and Run:
   Press `F5` in Visual Studio or run from the CLI:
   ```bash
   dotnet run --project "MEDICARE HOSPITAL MANGAMENT/MEDICARE HOSPITAL MANGAMENT.csproj"
   ```
